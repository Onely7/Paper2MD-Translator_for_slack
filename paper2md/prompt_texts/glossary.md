# 選ぶ語

- <用語の一覧> の行のうち、論文での意味が合う専門用語は、論文に一度しか出てこない語でも選ぶ。論文全体を一覧の訳語にそろえるためである。
- 一般的な語（model、data、result など）は、一覧にあっても選ばない。翻訳するときに普通に訳す。
- 一覧にない語は、論文の中で何度も出てくる専門用語、手法や構成要素の名前、モデルの構成の名前（base、big など）、データセットやタスクの呼び方（English-to-German など）、評価の指標や実験の設定を表す語を選ぶ。

# 用語の一覧

入力の <用語の一覧> は、研究室で使う訳語の一覧から、この論文の英文に出てくる語の行を機械的に拾ったものである。各行は「英語: 訳語［区分、その語が載っている書籍の数］」の形である。書籍の数の代わりに「研究室の方針」と書いた行は、研究室で決めた訳語を示す。

- 選んだ語が一覧にあり、論文での意味が同じなら、一覧の訳語をそのまま使う。長音記号、中黒、送り仮名も一覧のとおりに書く。
- 同じ英語の行が 2 つ以上あるときは、論文の分野と文脈に合う行を選ぶ。「定義:」が付いた行は、定義で見分ける。
- 「（論文では … とも書く）」「（論文では … と書く）」が付いた行は、論文がその語を略した形（attention mechanism を attention と書くなど）でも使うことを示す。略した形にも一覧の訳語を使う。
- 「（論文には近い表現の … が出てくる）」が付いた行は、一覧の英語は論文に出てこず、一覧が近い表現として挙げた語が論文に出てくる行である。近い表現には、意味の近い別の語も入っている。論文の語が一覧の英語と同じものを指すときだけ、一覧の訳語を使う。
- 論文が名前を付けて定義した手法や構成要素（「〜と呼ぶ」と書いた名前など）は、近い表現の行の訳語に置き換えない。
- 一覧には、論文とは別の分野の行も入っている。論文での意味が合わない行は使わない。

# 一覧にない語

- 一覧にない語のうち、手法、モデル、構成要素、指標などの名前として使われている語（Scaled Dot-Product Attention、compatibility function など）は、日本語に訳さず英語のまま書く。定着した日本語訳がありそうな語でも、訳さない。
- 一覧の語を含む言い回しで、残りの部分が普通の語なら、一覧の語の部分を一覧の訳語で書き、残りを日本語に訳す（sinusoidal positional encoding は正弦波の位置符号、learned positional embedding は学習可能な位置埋め込み）。
- 残りの部分に一覧にない専門用語があるときは、言い回し全体を英語のまま書く（recurrent layer、single-head attention）。英語と日本語を混ぜた訳語（recurrent 層 など）は作らない。
- 一般の文章でも使う普通の語（position、stack など）は、訳語表に入れない。翻訳するときに普通に日本語に訳す。
- 英語は、論文での書き方（大文字と小文字、ハイフン）のまま写す。
- 一つの英語には訳語を一つだけ決める。
