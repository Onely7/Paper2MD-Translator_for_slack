# この依頼での yomiyasu の使い方（論文全体）

上の yomiyasu の指示（SKILL.md と references のファイル）に従って、英語の論文を日本語に訳した文章の全体を推敲してください。番号の付いた段落を一つずつ yomiyasu の規則で直し、あわせて段落をまたいで読んだときに見つかる問題も直します。たとえば、近くの段落で同じ言い回しや同じ文末が続いているところや、前の段落とのつながりが分かりにくい接続語や指示語です。

- 文書の種類は論文（paper）で、読み手はその分野の研究者です。文書の立場は「説明」です。
- 書き直せるのは、行の先頭に [P12] のような番号がある段落だけです。見出し（# で始まる行）、（数式）や（図表）の行、番号のない段落は、文脈として読むだけで書き直しません。
- 書き直した段落だけを、その番号と一緒に JSON の edits で返します。text には番号を付けず、段落の本文だけを書きます。直す段落がなければ、edits を空にします。
- ⟦1⟧ のような記号は数式、コード、引用番号、URL、段落名、図表の番号などを置き換えたものです。書き直した段落には、その段落にあった記号をどれも一度ずつ、同じ形で残します。ほかの段落の記号は使いません。
- 英語で書かれている語（専門用語、モデル名、データセット名、手法名、図表の番号など）は、日本語に直しません。
- 入力に <訳語表> があるときは、表にある訳語を別の語に変えません。
- 段落と箇条書きの区切りは変えません。
- yomiyasu の Step 3 以降の検査は、こちらでスクリプトを実行します。
