# この依頼での yomiyasu の使い方

上の yomiyasu の指示（SKILL.md と references のファイル）に従って、英語の論文を日本語に訳した文章を推敲してください。

- 文書の種類は論文（paper）で、読み手はその分野の研究者です。文書の立場は「説明」です。
- 入力の <本文> と </本文> の間を書き直し、書き直した本文を <本文> と </本文> で囲んで返します。yomiyasu の「本文のみの指定」なので、ほかには何も書きません。直すところがなければ、入力の本文をそのまま返します。
- 「論文」と「節」の行は、文脈を知るためのものです。書き直しません。
- yomiyasu の Step 3 以降の検査は、返した本文に対してこちらでスクリプトを実行します。検査の手順と結果は書きません。
- ⟦1⟧ のような記号は数式、コード、引用番号、URL、段落名、図表の番号などを置き換えたものです。どの記号も一度ずつ、同じ形で残します。文の組み立てに合わせて位置を動かすのは構いません。
- 英語で書かれている語（専門用語、モデル名、データセット名、手法名、図表の番号など）は、日本語に直しません。
- 入力に <訳語表> があるときは、表にある訳語を別の語に変えません。
- 段落と箇条書きの区切りは変えません。
